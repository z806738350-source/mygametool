# Ink Studio browser runtime

These bundles contain @shapeshift-labs/ink-studio 0.1.0 by siliconjungle. The original MIT license is included in LICENSE.txt. [Pinned upstream source](https://github.com/siliconjungle/shapeshift-labs-ink-studio/tree/f4b5644a26f4a0d2a707b1c74dc58ea4f5ba692c)

The toolkit uses the upstream bake profile. The renderer bundles the standalone WebGL 2 renderer entry. Both are built with esbuild 0.28.2.

To rebuild, run `node scripts/prepare-ink-runtime.mjs /path/to/source.tar.gz` from the repository with dependencies installed. [Pinned source archive](https://codeload.github.com/siliconjungle/shapeshift-labs-ink-studio/tar.gz/f4b5644a26f4a0d2a707b1c74dc58ea4f5ba692c)
